# 🌟 Belook - بی لوک

یک پلتفرم تجارت الکترونیک مدرن و پیشرفته برای فروش محصولات آرایشی، بهداشتی و مراقبت از پوست

## ✨ ویژگی‌های کلیدی

- 🌍 **سه زبانه**: فارسی، عربی، انگلیسی با پشتیبانی کامل RTL/LTR
- 🎨 **طراحی مدرن**: استفاده از جدیدترین اصول UI/UX
- 🚀 **عملکرد بالا**: بهینه‌سازی شده برای سرعت و SEO
- 🔒 **امنیت پیشرفته**: احراز هویت، رمزنگاری و محافظت در برابر حملات
- 📱 **واکنش‌گرا**: طراحی کاملاً ریسپانسیو برای تمام دستگاه‌ها
- 🛍️ **تجربه خرید عالی**: سبد خرید پیشرفته، فیلترینگ و جستجو
- 👨‍💼 **پنل ادمین قدرتمند**: مدیریت کامل محصولات، سفارشات و کاربران
- 💳 **پرداخت امن**: یکپارچه‌سازی با درگاه‌های پرداخت معتبر

## 🛠️ تکنولوژی‌های استفاده شده

### Frontend
- **Next.js 14** - فریمورک React با App Router
- **TypeScript** - امنیت تایپ و توسعه بهتر
- **TailwindCSS** - استایل‌دهی مدرن و سریع
- **Framer Motion** - انیمیشن‌های روان و حرفه‌ای
- **shadcn/ui** - کامپوننت‌های UI زیبا و قابل تنظیم

### Backend & Database
- **Prisma ORM** - دسترسی به دیتابیس با امنیت تایپ
- **PostgreSQL** - دیتابیس قدرتمند و مقیاس‌پذیر
- **NextAuth.js** - احراز هویت امن

### State Management & Forms
- **Zustand** - مدیریت state سبک و قدرتمند
- **React Hook Form** - مدیریت فرم‌های پیشرفته
- **Zod** - اعتبارسنجی اسکیما

### Internationalization
- **next-intl** - پشتیبانی چند زبانه پیشرفته

## 🚀 شروع به کار

### پیش‌نیازها
- Node.js 18.0 یا بالاتر
- npm 9.0 یا بالاتر
- PostgreSQL 14 یا بالاتر

### نصب

1. نصب وابستگی‌ها:
```bash
npm install
```

2. تنظیم متغیرهای محیطی:
```bash
cp .env.example .env
```

سپس فایل `.env` را با اطلاعات خود ویرایش کنید.

3. راه‌اندازی دیتابیس:
```bash
npx prisma migrate dev
npx prisma db seed
```

4. اجرای پروژه در حالت توسعه:
```bash
npm run dev
```

وب‌سایت در آدرس [http://localhost:3000](http://localhost:3000) در دسترس خواهد بود.

### 🔑 اطلاعات ورود پیش‌فرض

**پنل ادمین** (http://localhost:3000/admin):
- ایمیل: `admin@belook.ir`
- رمز عبور: `admin123`

⚠️ **توجه**: برای امنیت، حتماً این اطلاعات را در محیط production تغییر دهید!

├── src/
